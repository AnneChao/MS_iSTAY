# MS_iSTAY

R code and data for reproducing the figures in the manuscript "A continuum of information-based temporal stability measures and their decomposition across hierarchical levels" by Chao et al. (2025).

This repository provides the R code and datasets used to generate all figures in the main text and Supporting Information of the manuscript. The scripts include functions for calculating information-based temporal stability and synchrony measures.

## Data

The analyses are based on biomass time-series data from the Jena Experiment:

1. **Community and population biomass data:** 21 observation years (2003 and 2005–2024) for 76 plots.
2. **Metacommunity biomass data:** 22 years (2003–2024) for 20 metacommunities.
3. **Population biomass data:** Time-series data for 462 populations used in the Supporting Information.

The datasets are provided in the `data/` folder and can be loaded directly by the R scripts.

## Repository contents

1. **Main_Document_R code.R:** R code used to generate all figures in the main text (Figures 1–4).
2. **Supporting_Information_R_code.R:** R code used to generate all figures in the Supporting Information (Appendices S1–S5).
3. **data/:** Datasets used for the analyses and figures.
4. **figures/:** Figures generated by the R scripts.
5. **Brief guide iSTAY.docx:** An introduction to iSTAY and a brief guide to reproducing the figures in Chao et al. (2025).
6. **MS_iSTAY.Rproj:** RStudio project file.

## Requirements

The scripts require R and the packages used for data analysis and visualization, including `tidyverse`, `lmerTest`, `gridExtra`, `ggpubr`, `mvtnorm`, `RColorBrewer`, and `ggtext`.

## Reproducing the figures

Open `MS_iSTAY.Rproj` in RStudio and run `Main_Document_R code.R` or `Supporting_Information_R_code.R` to generate the corresponding figures.

The output figures are saved in the `figures/` folder.
